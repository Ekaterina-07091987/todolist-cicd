# TodoList — клиент-серверное приложение

Приложение для управления списком задач. Frontend создан на React с помощью Vite, backend — на Node.js и Express. Клиент отправляет запросы к API, а сервер проверяет API-ключ и выполняет операции с задачами.

## Возможности

- Просмотр списка задач.
- Добавление задачи.
- Редактирование задачи.
- Удаление задачи.
- Проверка API-ключа для маршрутов `/api/tasks`.
- Отображение количества задач.

## Используемые технологии

- React
- Vite
- Node.js
- Express
- CORS
- dotenv

## Установка и запуск

### 1. Запуск backend

Откройте первый терминал в корневой папке проекта и выполните:

```powershell
cd todo-backend
npm install
```

Создайте файл `.env` в папке `todo-backend`. В нём должны быть строки:

```env
PORT=4000
API_KEY=my-secret-key
```

Если рядом уже есть `.env.example`, скопируйте его в `.env` командой:

```powershell
Copy-Item .env.example .env
```

Если файл `.env` уже создан, повторно копировать его не нужно.

Запустите сервер:

```powershell
node server.js
```

При успешном запуске появится сообщение о работе сервера на порту `4000`. Не закрывайте этот терминал, пока пользуетесь приложением.

### 2. Запуск frontend

Откройте второй терминал в корневой папке проекта и выполните:

```powershell
cd todo-frontend
npm install
npm run dev
```

Откройте адрес, который покажет Vite, например:

```text
http://localhost:5173/
```

Оставьте оба терминала открытыми: один обслуживает backend, другой — frontend.

## API

Базовый адрес API:

```text
http://localhost:4000/api/tasks
```

Для запросов к маршрутам задач клиент передаёт заголовок `x-api-key`. Его значение во frontend должно совпадать с `API_KEY` в файле `todo-backend/.env`.

| Метод | Маршрут | Действие |
|---|---|---|
| GET | `/api/tasks` | Получить список задач |
| POST | `/api/tasks` | Добавить задачу |
| DELETE | `/api/tasks/:id` | Удалить задачу по ID |
| PUT | `/api/tasks/:id` | Обновить задачу по ID |

Для добавления и обновления задачи сервер получает JSON с текстом задачи, например:

```json
{
  "text": "Проверить приложение"
}
```

## Проверка работы

1. Откройте приложение в браузере.
2. Введите текст задачи и нажмите **«Добавить»**.
3. Проверьте редактирование задачи с помощью кнопки-карандаша.
4. Проверьте удаление задачи с помощью кнопки-корзины.
5. Обновите страницу и убедитесь, что список снова загружается с backend.

## Хранение данных

В этой версии задачи хранятся в памяти backend-сервера. При перезапуске сервера список задач сбрасывается. Для постоянного хранения данных потребуется подключить базу данных.

## Настройки и безопасность

Файл `.env` содержит локальные настройки. Не добавляйте его в публичный Git-репозиторий. В репозиторий добавьте `.env.example` без настоящих секретных данных.

API-ключ во frontend доступен пользователям браузера. В этом учебном проекте он демонстрационный и не обеспечивает защиту, подходящую для production-проекта.

## CI/CD

Проект подключён к GitHub и автоматически развёртывается через Vercel.
Изменения в `main` публикуются в Production, а изменения в других ветках
создают Preview-деплои.
